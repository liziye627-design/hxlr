# Art Composer（歌词与作曲参数引擎）

## 概述
将主题输入转化为结构化歌词（A-B-C-D-A'）与作曲参数，并通过六维引擎校验与迭代优化，确保意象演进、悖论并置、声韵协调与情感分层。

## 适用场景
- 需要“中式声韵 + 哲思层”的歌词生成
- 需要把歌词与作曲参数联动输出
- 需要可复用、可检查、可迭代的创作流程

## 输入规范（推荐）
- 主题/叙事：如“分手”“怀旧”“城市漂泊”
- 情绪走向：上升/转折/下沉
- 关键意象：1-2 个（可选）
- 禁用词/推荐词：可选
- 结构约束：默认 A-B-C-D-A'
- 放宽强度：strict / balanced / loose（默认 balanced）

## 输出格式（固定）
```text
【歌词】
A 主歌1（4行，微观）
B 主歌2（4行，中观）
C 副歌（4行，宏观）
D 桥段（2行，悖论升华）
A' 主歌重奏（4行，微观但深化）

【作曲参数】
- 节奏：主歌/副歌/桥段
- 旋律：微观/中观/宏观 音程走向
- 音色：主歌/副歌/桥段
- 人声处理：主歌/副歌/桥段

【自评摘要】
- S 递进性：通过/未通过
- K 意象演进：通过/未通过
- I 悖论保留：通过/未通过
- L 声韵物理：通过/未通过
- L 情感分层：通过/未通过
- S 结构螺旋：通过/未通过
- 迭代建议：...
```

## 六维引擎（核心规则）

### S: Scalability（递进性架构）
- 微观层（1-4句）：≥2 个可触摸感官词，句长 ≤12 字
- 中观层（5-8句）：引入时空流动意象（路/时光/脚步），句长 12-16 字
- 宏观层（9-12句）：≥1 个哲学关键词（生命/人生/终究），句长 ≥14 字
- 主题为爱情时：
  - 微观禁用：爱/喜欢/想念，推荐：瞳孔/指尖/呼吸频率
  - 中观禁用：永远/承诺/未来，推荐：车站钟表/未寄出的信/褪色车票
  - 宏观禁用：幸福/痛苦/命运，推荐：徒劳/难舍/无怨

### K: Key Images（意象锚点）
- 全曲锁定 1-2 个核心意象，必须演变
- 明度或饱和度梯度变化（如黑→灰→白）
- 文化记忆优先（月亮/车站/书信/雨天）
- 禁止同一意象原样重复超过 3 次

### I: Irony（悖论升华）
- 识别不可调和矛盾，不用“但是/然而”化解
- 以时间/空间/存在层并置为真理
- 推荐表达："难忘是真的，无怨也是真的"

### L: Lyrical Flow（声韵物理）
- 每段锁定 1 个主韵母（-an/-ang/-ing/-ou）
- 句尾声调与情感走向匹配：
  - 上升期：一声/二声
  - 转折期：三声
  - 下沉期：四声
- 同韵词 16 行内重复 >2 次，触发替换

### L: Layered Emotion（情感分层）
- 每句≥2层含义（表层+深层）
- 主歌1：否认，主歌2：接纳，副歌：超越
- 触发机制：具体意象→对称句式→悖论升华→声韵设计

### S: Structure（结构对称与螺旋）
- A-B-C-D-A' 结构固定
- A' 段需复用 A 段关键词，但语义升级
- D 段 2 行，用自由韵完成悖论升华

## 执行流程（建议）
1. 主题解析：提取核心矛盾、意象、情感走向
2. 六维并行生成：按层级生成 A/B/C/D/A'
3. 自评与迭代：任一维度失败则局部重生成

## 放宽规则（避免僵硬）
- strict: 全部硬约束，适合实验性写作
- balanced: 允许 1-2 处破格但不破坏结构
- loose: 声韵或长度可小幅偏离，优先保留意象与悖论

## 质量闸门（必测）
- 去掉微观细节后歌词仍成立 => 失败（说明微观未绑定）
- 将“无怨”替换为“原谅”后语义仍成立 => 失败（悖论被消解）
- 全部韵脚 100% 严格 => 失败（缺乏灵活性）

## 快速示例（调用方式）
“主题：分手与城市漂泊，意象：车站与雨，情绪走向：下沉，禁用词：永远/承诺，输出 A-B-C-D-A'，严格度 balanced。”
